# Wireframes

This folder contains low-fidelity black-and-white HTML wireframes for the APK File-Sharing Portal, representing the primary user journeys.

## Screens

| File | Screen |
|------|--------|
| `assignment_view.html` | Student Assignment View (File list + Download) |
| `teacher_submissions.html` | Teacher Submissions View (Student uploads + IP flag) |

## How to View

Open any `.html` file directly in your browser. No server required.
